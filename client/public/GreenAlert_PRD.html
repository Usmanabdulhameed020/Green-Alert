GreenAlert - File-by-File Codebase & Function Guide

Complete Technical Explanation of Every File and Function Across Client and Server

1. Backend Server Files (`/server/src`)

📁 server/src/server.js

Purpose: Main entry point of the backend server application.

server.listen(PORT): Binds Express HTTP and Socket.IO server to network port 5000 and connects to MongoDB.
📁 server/src/app.js

Purpose: Express application configuration middleware setup.

app.use(cors()): Configures Cross-Origin Resource Sharing so browser clients on Vercel can access the API.
app.use(helmet()): Sets security HTTP headers (X-Frame-Options, CSP, X-XSS-Protection).
app.use('/api/v1/...'): Registers API route routers.
📁 server/src/controllers/report.controller.js

Purpose: Handles incident report management logic.

createReport(req, res): Saves new report in MongoDB with 2dsphere GeoJSON location point, auto-assigns nearest organization, triggers email alert, and emits Socket.IO event.
getAllReports(req, res): Fetches public environmental reports for explore map with filter parameters.
updateReportStatus(req, res): Updates ticket resolution status, logs audit event, and sends real-time socket + email notification.
getMyReports(req, res): Fetches incident reports logged by the currently authenticated user.
📁 server/src/controllers/auth.controller.js

Purpose: Authentication and user session controller.

register(req, res): Hashes password with bcrypt (12 salt rounds), creates User document, signs JWT token.
login(req, res): Compares bcrypt password hashes and issues signed JWT session token.
forgotPassword(req, res): Generates 6-digit verification code and dispatches email via Brevo.
📁 server/src/controllers/ai.controller.js

Purpose: AI enrichment & duplicate detection controller.

analyzeReport(req, res): Sends report text to Gemini AI via `generateText()`. Parses structured JSON for summary, category, and severity. Falls back to `localAnalysis()` if AI is unavailable.
findDuplicates(report): Scans same-category reports created within 7 days and computes Jaccard word similarity to flag duplicate tickets.
📁 server/src/services/ai.service.js

Purpose: Reusable Gemini AI content generation service with multi-model fallback chain.

generateText(prompt): Executes a fallback loop across candidate models (`gemini-2.0-flash`, `gemini-1.5-flash`, `gemini-1.5-pro`) to ensure reliability even under rate limits.
📁 server/src/services/email.service.js

Purpose: Transactional email dispatcher via Brevo API SDK.

sendWelcomeEmail(to, name): Sends welcoming HTML email to new users.
sendReportSubmittedEmail(to, name, report): Sends receipt email to citizens when report is logged.
sendReportStatusEmail(to, name, title, status): Notifies citizen when an agency updates their ticket status.
📁 server/src/services/socket.service.js

Purpose: Socket.IO real-time WebSocket connection manager.

initSocket(server): Attaches Socket.IO server, manages user rooms (`user:id`), and handles real-time message broadcasting.

2. Frontend Client Files (`/client/src`)

📁 client/src/pages/dashboard/CreateReport.jsx

Purpose: 7-step interactive report creation wizard.

fetchGeocodeWithFallback(address): Progressive search algorithm. If exact address is unindexed, strips building numbers and falls back to nearest known landmarks/neighborhoods.
reverseGeocode(lat, lng): Queries OpenStreetMap Nominatim reverse geocoder on map click or current GPS locate.
handleUseCurrentLocation(): Obtains hardware GPS coordinates via `navigator.geolocation.getCurrentPosition()`.
handleSubmit(): Uploads photos/videos to Cloudinary and submits complete report object to Express backend API.
📁 client/src/components/map/MapLibreMap.jsx

Purpose: Multi-source GIS satellite map component.

MapLibreMap(...): Renders GPU-accelerated satellite maps with MapLibre GL JS. Defaults to **Google Hybrid** tile provider and renders clustering and active sonar pulse layers.
handleSwitchProvider(providerId): Switches active basemap style between Google Hybrid, Google Pure Satellite, and Esri HD Aerial.
📁 client/src/contexts/CitizenContext.jsx

Purpose: Global React state context provider for citizen state, reports list, and notifications.

CitizenProvider({ children }): Holds state for reports, user profile, and notifications; exposes API wrapper functions (`createReport`, `fetchReports`, `logout`).
📁 client/src/layouts/DashboardLayout.jsx

Purpose: Responsive layout shell for the citizen dashboard.

DashboardLayout(): Renders top navigation bar, collapsible desktop sidebar, mobile drawer, and Socket.IO real-time notification listener.
